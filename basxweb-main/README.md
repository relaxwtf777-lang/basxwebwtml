# Proxy Weaver

ผมอยากได้เว็ปที่เอาใช้คู่กับ IPv4 ได้โดยเอา IPv4+:3001 ไปใส่แล้วให้เว็ปมันรันให้คือโปรเจคนี้พอเราเอา ipv4 ไปใส่คู่กับ :3001 จะเข้าเว็ปผมได้แต่ตรง URL เว็ปมันเป็นเลข IP ผมอยากให้คุณทำเว็ปที่เอาเลข IPv4+:3001 ไปใส่แล้วเว็ปมันเปิดเว็ปอีกทีให้และชื่อ URL ไม่มีเลข IPv4 แล้วแต่เป็น BASX + อะไรก็ได้สุ่มๆ เอาที่ไม่ตรงกับของเครื่องอื่นๆ ที่ใช้พร้อมกันโดยแยกเครื่องจาก IPv4 ที่ใส่ไป
